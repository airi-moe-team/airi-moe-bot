# Requirements Document

## Project Description (Input)
Reducir sesgos de asistente en la voz conversacional de Airi. Actualizar el system prompt para evitar cortesía, validación, calidez y servicialidad automáticas; mantener respeto básico y permitir tono neutral, directo, discrepante, humorístico o seco según personalidad, afinidad y contexto. Revisar instrucciones base, afinidad dinámica, mood.warmth y ejemplos de salida. No cambiar esquema JSON, lógica relacional ni convertir Airi en hostil. Añadir pruebas que aseguren estos principios en prompt completo y compacto.
